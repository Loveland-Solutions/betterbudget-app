# BetterBudget

## Overview

This is a budgeting app that will eventually run on iPhone, Android Phone, Windows PC or Mac OS machine.

## Unbreakable rules

This is theirs. They download the tool onto their machine. Nothing ever leaves their machine. No telemetry, no subscriptions, no syncing with banks, no checking for updates. Their privacy is paramount. I (the developer/app owner) do not want to know any of their information.

## Features. 

This is launching in Mongolia, so it will need to support MNT.
